# Atalhos do PDV

Os atalhos disponíveis podem variar conforme a tela, as permissões e a configuração da loja. Observe sempre a legenda exibida no próprio PDV.

## Durante a venda

| Tecla | Ação mais comum |
|---|---|
| **F5** | Cancelar item |
| **F6** | Cancelar venda |
| **F7** | Desconto no item |
| **F8** | Desconto ou acréscimo na venda |
| **F9** | Abrir opções do sistema |
| **F10** | Pesquisar produto |
| **F11** | Identificar ou pesquisar cliente, conforme a tela |

## Durante o pagamento

| Tecla | Forma de pagamento ou ação |
|---|---|
| **F1** | Dinheiro |
| **F2** | Voucher |
| **F3** | Cartão |
| **F4** | PIX |
| **F10** | Emitir NF-e modelo 55, quando habilitada |
| **F11** | Promissória |
| **F12** | Outras finalizadoras |
| **Ctrl+F12** | Parcelamento, quando disponível |

## Opções do sistema — F9

Conforme a permissão, o menu pode oferecer:

- troca de operador;
- bloqueio do caixa;
- sangria e suprimento;
- abertura da gaveta;
- administração do TEF;
- pesquisa de pedidos;
- recebimento de contas;
- consulta de ofertas;
- reinicialização do PDV Monitor;
- configurações autorizadas ao supervisor.

!!! warning "Ações de supervisor"
    Cancelamentos, descontos, reabertura de movimento e configurações podem solicitar usuário e senha de supervisor.

!!! note
    Em restaurante, comandas, mesas ou outros modos de operação, alguns atalhos assumem funções específicas. Use a legenda da tela como referência principal.
